# AI Dashboard 文档目录

## 目录规则

- `design/en/`：英文设计文档原稿。
- `design/zh/`：中文设计文档。后续设计文档更新需要同步维护中英文版本。
- `logs/en/`：英文变更日志和交接记录原稿。
- `logs/zh/`：中文变更日志和交接记录。
- `reference/`：外部参考文档，不作为 AI Dashboard 设计规范的唯一来源。

## 当前语言状态

- 英文设计文档和英文日志已保留在各自的 `en` 目录。
- 中文日志已从最新的 Golden 标注工作开始补齐。
- 后续新建的项目文档默认只使用中文；如果是已有英文文档的更新，则同步更新对应中文版本。

## 规则优先级

项目协作中已经确认的对话决策优先于历史文档；设计文档用于记录稳定规则和检查遗漏，日志用于记录具体变更、验证结果和交接事项。
