# 17 变更日志：识别任务

## 本次范围

- 文件上传现在返回 HTTP 202、`job_id` 和 `queued` 状态。
- SQLite 保存 queued、running、completed、failed 等任务状态。
- 当前进程内后台任务执行确定性的 Python Workbook 扫描。
- 前端轮询任务，并在“识别进度”中显示阶段和进度。

## 边界说明

这是 MVP 任务边界，不是生产级队列。服务重启可能中断进程内任务；正式环境仍需要持久化 Worker 和队列。当前任务不调用 AI，也不生成业务数值。

## 验证结果

- 上传返回 `queued` 和任务 ID。
- 任务轮询最终变为 `completed`。
- 重新读取项目可获得已完成的文件版本和 Sheet 扫描摘要。
