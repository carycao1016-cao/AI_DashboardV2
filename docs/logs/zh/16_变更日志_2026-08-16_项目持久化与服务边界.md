# 16 变更日志：项目持久化与服务边界

## 本次范围

- React/Vite 应用整理到 `frontend/`。
- Python FastAPI 入口整理到 `backend/src/app/`。
- 增加本地 SQLite MVP，用于保存 `Project` 和 `SourceFileVersion` 元数据。
- 项目创建、项目读取和文件版本上传改为调用后端 API。

## 接口约定

- `POST /api/projects` 创建项目容器；创建项目时不固定市场和 Wave。
- `GET /api/projects/{project_id}` 返回项目及其文件版本。
- `POST /api/projects/{project_id}/source-versions` 要求项目已存在，并保存扫描元数据。
- 原始上传文件仍保存在本地上传目录；SQLite 只保存元数据和扫描摘要。

## 过渡边界

现有 `parser_poc` 继续作为已经测试过的 Parser 核心，由后端暂时调用。只有在 Golden 和离线测试契约持续通过后，才迁移到 `backend/src/app/pipelines/`。
