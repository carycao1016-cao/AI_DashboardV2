## 已确认规则

- Tab 识别是通用方案，A 列和厂商名称只能作为线索。
- 物理表按 Sheet 和范围独立保存；显著性按表检测。
- 支持 Header 内联、独立行、相邻列、下一行、同单元格、独立 Sheet 和混合布局。
- `A/a/B/b` 是大小写敏感的源标签，不是 Excel 列号。
- 缺失 Base 保持空，不从其他表或 Sheet 继承。
- Count/Percentage/显著性变体只有题号、标题、选项、完整 Header、Market、Wave、Base 严格一致时才合并。
- Python 扫描和验证全 Workbook；AI 只接收轻量摘要和必要 Detail Window。
- Golden evaluator 只输出状态统计，不把业务值写入评估报告。
- Python 基线为 3.12；后续测试使用同一套 Contract 和 Golden 集。
