# 18 变更日志：显式 AI 识别

## 本次范围

- 为已完成 Python 扫描的文件版本增加显式识别接口。
- 上传不会自动调用 AI Provider。
- `PARSER_AI_ENABLED=false` 时默认关闭 AI 识别。
- 开启后使用后端配置的 Ark 档案和 `PARSER_AI_MAX_SHEETS` 上限。
- 识别结果只保存任务状态摘要；源数值仍由 Python 负责。

## 安全边界

前端不会接收或提交 API Key。AI 关闭时接口会拒绝请求；默认 Sheet 上限为 1，适合受控 Smoke 测试。扩大范围前必须先完成单独的 Golden 评估决策。
